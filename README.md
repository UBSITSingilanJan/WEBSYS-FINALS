# WEBSYS-FINALS

## Resident masterlist and applications

For a fresh installation, import `financialaidsystem-new.sql`. For an existing installation, back up the database and run `migrations/add_resident_application_relationship.sql` once. Worker accounts can use **Resident Masterlist** to search, encode, and update resident profiles. New online applications are linked to the resident profile associated with the applicant's account. Workers can link legacy applications to existing resident records from **Manage Applications**; applications with no reliable resident match remain unlinked rather than being assigned by name alone.
